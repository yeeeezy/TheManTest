# [FEAT-040] 影子持枪 mesh + 身体瞄准 IK（低优先）

**创建日期：** 2026-06-24
**状态：** planned（低优先，依赖 FEAT-038/039）
**Archive 文件：** `archive/FEAT-040-shadow-weapon-aim-ik.md`

## 功能概述

让第三人称投影更完整：①影子手里"握着枪"（第三人称武器 mesh 只投影）；②身体上半身 BBBAimIK 朝相机视线方向，让影子枪口跟着玩家瞄准方向走（可选"摆正"）。

用户明确这两点**优先级较低**：影子持枪算需求，但瞄准 IK 的精度/摆正做不做都行。放在 FEAT-038/039 主体跑通之后。

---

## 设计决策（2026-06-24 与用户确认）

- **影子持枪是需求**，但身体 AimIK 瞄准目标的精度、以及"上半身摆正与否"优先级低——可后做或简化。
- 影子枪用独立的第三人称武器 mesh（`SetOwnerNoSee(true)` + `bCastHiddenShadow=true`），与第一人称手上那把武器（挂 ArmsMesh、玩家可见）分开；FP 武器链路完全不动。
- 身体 BBBAimIK 目标 = 相机/视线方向（让影子枪口指向玩家瞄的地方）。

---

**涉及 C++ 文件：**
