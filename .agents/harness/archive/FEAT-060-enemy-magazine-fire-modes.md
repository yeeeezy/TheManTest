# FEAT-060 — 通用敌人弹匣三连发持续扫射与换弹

**状态：** done
**完成：** 2026-07-30

默认20发、只由普通射击消耗；三连发、持续扫射、换弹、子弹类和节奏均数据化，供不同 Enemy/GAS 能力复用。

## 实现与验证

- 通用弹匣默认 20 发；自动射击每发消费，三连发=3×0.12s、扫射=10×0.09s。
- 空匣阻止普通射击并允许 Reload；换弹补满。范围轰炸不消费普通弹匣。
- 枪口优先 Socket，缺失时用可配置局部 Offset；弹体类可替换。
- TMIIR Burst/Continuous/Aim Reload 原动画迁入并绑定正式 Skeleton；资产验证及耗弹/补弹自动化通过。
